Educational Project | Text Classification

Smart Email Router

A prototype that classifies incoming university inquiries and routes each one to the right team: IT, Billing, or Admissions.

How it works

  • Reads the content of an inquiry and assigns it to one of three categories.
  • Sends requests that don't clearly fit a category to manual review instead of guessing.
  • Keeps a person involved in ambiguous cases so unclear requests are not misrouted.
  • Text classification
  • Request routing
  • Human-in-the-loop review
Coursework Project | Retrieval-Augmented Generation

Open-Book IT Policy Assistant

A retrieval-augmented generation (RAG) prototype that answers questions about fictional university IT policies using the policy text itself.

How it works

  • Retrieves the policy sections most relevant to a user's question.
  • Generates an answer grounded in the retrieved sections rather than general knowledge.
  • Works "open book," so answers stay tied to the source policy content.
  • Retrieval-augmented generation
  • Document retrieval
  • Grounded answers
